# Yazi Assets

- `themes/`: bundled Yazi flavors, each shaped as `<name>.yazi/flavor.toml`.
- `plugins/`: bundled Yazi plugins: `auto-layout`, `git`, `lazygit`, and `starship`.

## Bundled Flavors / Themes
